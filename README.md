# FloatTask

Installers and website for **FloatTask**, the always-on-top task widget for Mac and Windows.

**Download:** https://floattask.com · or the [latest release](https://github.com/CodeCraftrRyan/floattask-releases/releases/latest)

Found a bug? [Open an issue](https://github.com/CodeCraftrRyan/floattask-releases/issues/new) — or use **Settings › About › Report a bug** in the app, which fills in your version and OS.

This repository is published automatically; the app's source code is kept separately.
